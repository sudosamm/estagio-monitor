Como funciona

{% if config.texto_captacao and modo != "editar" %}

{{ config.texto_captacao }}

{% endif %}
  1. O(a) representante legal da concedente, ou alguém autorizado por ele(a), preenche este cadastro com os dados da empresa ou órgão, os cursos e as vagas.
  2. Quem preenche ganha uma conta: entra quando quiser para ver o andamento e, enquanto a escola não analisa, corrigir os dados e as vagas.
  3. O orientador ou o coordenador do curso analisa. A decisão aparece no sistema e chega por e-mail.
  4. Aprovado, você vira responsável pela concedente no sistema: cadastra a equipe e o supervisor indicado ganha acesso para confirmar as presenças. As vagas ficam como foram aceitas.
Os dados são usados só para organizar o estágio, conforme a Lei nº 11.788/2008 e o Aviso de Privacidade.
